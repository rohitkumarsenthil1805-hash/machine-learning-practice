# Machine Learning Practice 

A collection of Python scripts and practical examples created while learning **Data Science, Data Visualization, Statistical Analysis, and Machine Learning**. This repository focuses on hands-on implementations using standard datasets and financial data.

##  Objectives

- Practise data manipulation and descriptive statistics.
- Explore datasets using Pandas and NumPy.
- Visualize trends, distributions, and relationships using Matplotlib and Seaborn.
- Implement fundamental machine learning algorithms using Scikit-learn.
- Develop a foundation for real-world data science projects.

##  Programs and Topics

| Program | Description | Libraries / Concepts |
|---|---|---|
| **Iris Dataset Analysis** | Explore the Iris dataset, perform data transformations, and calculate descriptive statistics. | Pandas, NumPy |
| **Iris Classification** | Classify Iris flower species using Logistic Regression, with train-test splitting and evaluation. | Scikit-learn, Classification |
| **NIFTY 50 Prediction** | Train a Random Forest Regressor using historical NIFTY 50 index data. | yfinance, Scikit-learn, Regression |
| **Data Visualization Lab** | Create line plots, bar charts, histograms, scatter plots, box plots. | Matplotlib, Seaborn |
| **Supplementary Exercises** | Practise Python data structures, utility functions, and related programming concepts. | Python |

##  Tools and Technologies

- **Programming Language:** Python 3
- **Data Analysis:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-learn
- **Data Source:** Yahoo Finance through yfinance
- **Development Environments:** Jupyter Notebook, Google Colab
- **Version Control:** Git and GitHub
