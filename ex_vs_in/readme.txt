# Personality Prediction API Using FastAPI, Pydantic and Pickle

A machine learning model deployment project that demonstrates how to integrate a trained Scikit-learn model with FastAPI, validate incoming data using Pydantic, serialize and deserialize models using Pickle, and test REST API endpoints using Postman.

The primary objective of this project is to understand the fundamentals of deploying and serving machine learning models through REST APIs.

## Project Overview

This project demonstrates how a trained machine learning model can be integrated into a backend application and exposed through an HTTP API.

The implementation focuses on the backend workflow involved in receiving structured input, validating request data, loading a serialized model, generating predictions, and returning JSON responses.

### Key Learning Outcomes

- Model serialization and deserialization using Pickle.
- Loading trained machine learning models into Python applications.
- Developing REST API endpoints using FastAPI.
- Validating incoming request data using Pydantic.
- Processing structured JSON requests.
- Generating predictions through a deployed machine learning model.
- Testing HTTP POST requests and JSON responses using Postman.

## Application Workflow

The application follows the workflow below:

1. A trained machine learning model is serialized and saved as a `.pkl` file.
2. Pickle is used to load the saved model into the FastAPI application.
3. A Pydantic schema defines the structure and data types of incoming requests.
4. An API client sends a JSON request to the `/predict` endpoint.
5. FastAPI receives the request and validates the input using Pydantic.
6. The validated features are passed to the loaded machine learning model.
7. The model generates a prediction.
8. FastAPI returns the prediction as a JSON response.

```text
          Postman
             |
             | POST Request (JSON)
             |
             v
       FastAPI Endpoint
             |
             v
      Pydantic Validation
             |
             v
      Feature Extraction
             |
             v
       Loaded ML Model
             |
             v
      Model Prediction
             |
             v
        JSON Response
```

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
```

### 2. Navigate to the Project Directory

```bash
cd personality-prediction-api
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate the environment using Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 4. Install Dependencies

```bash
python -m pip install fastapi uvicorn pydantic scikit-learn
```

### 5. Start the FastAPI Application

```bash
python -m uvicorn app:app --reload --port 5000
```

The application will be available at:

```text
http://127.0.0.1:5000
```

Interactive API documentation:

```text
http://127.0.0.1:5000/docs
```

## API Documentation

### Prediction Endpoint

| Property | Description |
|---|---|
| Endpoint | `/predict` |
| HTTP Method | POST |
| Content-Type | application/json |
| Request Format | JSON |
| Response Format | JSON |

### Testing the API Using Postman

1. Open Postman.
2. Select the POST HTTP method.
3. Enter the following endpoint:

```text
http://127.0.0.1:5000/predict
```

4. Navigate to Body, select raw, and choose JSON.
5. Provide the required input features in JSON format.

**Sample Request**

```json
{
    "Time_spent_Alone": 4,
    "Stage_fear": 0,
    "Social_event_attendance": 4,
    "Going_outside": 6,
    "Drained_after_socializing": 0,
    "Friends_circle_size": 13,
    "Post_frequency": 5
}
```

The input values must conform to the data types and encoding expected by the trained model.

**Sample Response**

```json
{
    "prediction": "introvert"
}
```

The prediction is generated by the trained machine learning model based on the submitted input.

## Technical Implementation

### 1. Model Serialization Using Pickle

Pickle is used to serialize a trained machine learning model and load it into the application without requiring retraining.

```python
import pickle

with open("classifier.pkl", "rb") as file:
    classifier = pickle.load(file)
```

### 2. Request Validation Using Pydantic

Pydantic is used to define the expected input structure and validate incoming request data.

```python
from pydantic import BaseModel

class Behavior(BaseModel):
    Time_spent_Alone: float
    Stage_fear: float
    Social_event_attendance: float
    Going_outside: float
    Drained_after_socializing: float
    Friends_circle_size: float
    Post_frequency: float
```

### 3. REST API Development Using FastAPI

FastAPI provides the endpoint for receiving validated input, executing model inference, and returning the prediction.

```python
@app.post("/predict")
def predict(data: Behavior):
    # Extract input features
    # Generate model prediction
    # Return JSON response
    ...
```

### 4. API Testing Using Postman

Postman is used to test the API by sending HTTP POST requests with JSON payloads and inspecting the server responses.
